# SecureHome Integrated Project

## Structure Guide
1. Put ALL your `.html` files into the `/templates/` directory.
2. Put ALL your `.js` and `.css` files into the `/static/` directory.
3. Your Machine Learning and Database scripts are organized in `/ml_pipeline/`.

## How to Run
1. Install dependencies: `pip install -r requirements.txt`
2. Set up MySQL using `database.sql`.
3. Start the application: `python app.py`
